# DocChat Evaluation

This folder contains a small manual RAG evaluation set.

## Workflow

1. Place the fixture PDFs in `evaluation/fixtures/french/` and `evaluation/fixtures/arabic/`.
2. Upload one fixture PDF through the DocChat UI.
3. Wait until the document status is `ready`.
4. Ask the listed questions.
5. Record the observed answer, sources, and verdict in the fixture question table.

PDF files are local fixtures and are not committed.
